1.27（a / b）1.27a：2016-03-15 · 1.27b：2016-12-132011 年以来首个补丁
时代背景：时隔 5 年（2011–2016）暴雪重启更新，先做系统兼容。
游戏功能性更新
  • 支持 Windows 7 / 8.1 / 10；新增 Mac 10.10 / 10.11 安装器。
  • 选项新增 1920×1080 分辨率（但无宽屏适配，画面拉伸）。
  • 1.27b：地图文件大小上限 8MB → 128MB。
地图编辑器更新
  • 1.27b：新增「脚本校验」功能。
BUG 修复
  • 修复闪电链崩溃。
  • 1.27b：自定义 .blp 贴图文件不再导致 Mac 崩溃。
  • 已知问题：窗口化下伽马设置不生效、西里尔字符仍无法显示、Mac 不支持编辑器。
1.28（含 1.28.1–1.28.6）1.28：2017-04-05小修补丁系列
游戏功能性更新
  • 新增显示模式：窗口化全屏（默认）、窗口化（-window）、原生全屏（-nativefullscr）。
  • 窗口模式新增鼠标光标限制选项（仅游戏窗口内活动，菜单可解除）。
  • 数据迁移不再需以管理员身份运行即可访问游戏存档。
  • 优化安装与更新效率。
安全 / 底层变动
  • Return Bug 依旧可用：原版「不安全的类型转换」漏洞已在 1.24a（2009）修补，但社区用绕过写法仍可在自定义地图中执行任意代码。
  • 文件结构迁移：CD-Key 从 War3.mpq 内加密的 font 文件移出，改为安装目录下的独立文件 roc.w3k / tft.w3k。
地图编辑器更新
  • 修复「脚本校验」的图标与词条。
BUG 修复
  • 修复 CommandFunc.txt 特殊坐标（0,-11）/（-2147483648,-2147483648）导致命令卡错误隐藏。
  • 修复比赛结束断战网、视频播放器任意分辨率播放、Windows GameDVR 失效。
  • 1.28.2：复活死尸不再导致 Windows/Mac 跨平台反同步；编辑器 Test Map 写入临时目录。
1.292018-04-10（PTR：2018-02-21）经典时代最大补丁
里程碑：真正的宽屏适配、24 人游戏、Return Bug 彻底封死、Game.dll 不再独立暴露，以及编辑器上限与原生函数的爆发式扩容。
游戏功能性更新
  • 真正的宽屏适配：原生 16:9 宽屏支持，不再拉伸变形（界面加黑边、菜单加黑柱防拉伸）。
  • 24 人游戏：大厅支持最多 24 名玩家；队伍颜色扩展。
  • 12 种新队伍颜色：栗色 / 海军蓝 / 青绿色 / 紫罗兰 / 小麦色 / 桃色 / 薄荷色 / 薰衣草色 / 煤色 / 雪白色 / 翡翠色 / 花生色。
  • 官方 Streamer/Caster API：可读取金币、木材、食物、APM 等观战信息（无需第三方破解）。
安全 / 底层（社区重点）
  • Return Bug 彻底封死：1.29 起 return bug 变体完全失效。
  • 依赖它的地图需改用原生哈希表函数；部分「返回 null 却声明为 string」的旧地图无法运行。
  • Game.dll 不再独立暴露：Game.dll / Storm.dll 被合并进 Warcraft III.exe，不再以独立 DLL 形式存在于安装目录。
  • War3Patch.mpq 移除：补丁文件并入其他 MPQ（对战平台需改用 War3x.mpq 内的 blizzard.j / common.j）。
平衡性机制改动
  • 剑圣暴击口径改动：暴击倍率改为只作用于基础攻击、不再放大装备加成伤害。1.31 改回「含全部伤害」。
编辑器上限与原生函数爆发式扩容
  • 对象上限 → 30,000（分项：中立单位 2048、中立建筑 384、玩家单位 4320、玩家建筑 2400、物品 1024）。
  • 地图尺寸 → 480×480；瓦片上限 → 16。
  • 最大执行数 → 1,666,666（旧值 300,000）；最大食物 → 999（旧值 300）；最大资源 → 9,999,999；数组大小 8192 → 32768。
  • 90+ 个新原生函数：特效全控制（缩放 / 旋转 / 俯仰，替代假人单位做弹道 / 特效系统）、能力 / 物品 / 单位增强控制、鼠标悬停与点击响应。
BUG 修复
  • 战队可重新创建；Mac 客户端可启动；韩语区启动；多处缺失贴图定位；默认分辨率不再异常。
  • 系统支持（官方注明）：1.29 为最后一个支持 Windows XP 的版本，此后补丁不再支持 XP。
  • 已知问题：原生全屏无法改分辨率、部分原生函数改名 / 暂时停用（Set/GetAbilityOnXXXX、SetUnitNameAll、PlaySpecialEffect 等）。
1.302018-08-08（含 1.30.1–1.30.4）底层迁移
游戏功能性更新
  • 升级反作弊系统。
  • 更新观战 API，可导出更多游戏信息。
  • 启用 Large Address Aware（部分机器最多使用 3GB 内存）。
  • 游戏文件由 MPQ 迁移至 CASC 文件系统。
平衡性机制改动（科技树 · 训练建筑 · 商店）
  • 灵魂行者改在牛头人图腾训练（原灵魂归宿），热键 T → W；图腾改由据点解锁（原堡垒）、不再需战争磨坊，灵魂行者排到命令栏第一格。
  • 山岭巨人嘲讽 3 秒后再次触发。1.32.10 回调。
  • 两项升级默认解锁：女猎手「哨兵」（另设 180 秒持续时间，原永久）、角鹰兽「驯服角鹰兽」——对应升级项从科技树移除。
  • 亡灵「骨质增强」科技移除，效果并入「骷髅精通」。
  • 科技树前置变动：女猎手「月刃」改由远古之树解锁；战争古树移除「哨兵」升级；奇美拉栖木不再需要风之古树。
  • 商店物品池调整：亡灵遗物之墓「献祭头骨」不再需要坟场。
  • 人类步兵「顶盾」免疫伤害的重复结算 Bug 修复（原 30% 反弹时免疫伤害被算两次；修正为 30% 反弹 / 70% 受 50% 伤害）。
地图编辑器更新
  • 最多可选 16 瓦片（含悬崖）。
  • 新增原生函数：BlzPlaySpecialEffect（特效播放）。
  • 新增原生函数：BlzSpecialEffectAddSubAnimation / BlzSpecialEffectRemoveSubAnimation（子动画增删）。
  • 新增原生函数：BlzSpecialEffectClearSubAnimations（清空子动画）。
  • BlzSetSpecialEffectHeight 计入地形高度。
BUG 修复
  • 修复自定义能力目标参数崩溃、网络延迟恢复、原生全屏鼠标、带弹幕升级的蒸汽坦克占用 4 食物等。
1.312019-05-28（含 1.31.1 · PTR 2019-04-24）Reforged 前最后经典补丁
里程碑：底层图形 API 现代化 + 编辑器支持 Lua。
游戏功能性更新
  • 集成 Direct3D 11 与 Metal 图形 API；Windows / Mac 支持 64 位（Mac 弃用 32 位）。
  • 客户端非激活时关闭声音；扩展窗口模式。
  • RoC 关闭战网（混沌之治玩家自动获得冰封王座）。
平衡性机制改动
  • 疾风步冷却从施法时改为破隐时开始计算，同时冷却 5s → 2s（全等级）。
  • 剑圣暴击改回「含全部伤害」——撤销 1.29 的「仅基础攻击」口径。
  • 新增物品「祭礼匕首」——亡灵遗物之墓上架，牺牲己方单位换群体回血。
  • 人类「火焰之球」重做为反治疗定位：移除溅射、新增「降低治疗效果与回血 35% / 3 秒」的减益效果。2.0.2 被「减速之球」取代。
  • 骑士新升级「裂甲之刃」（兵营研究，需城堡 / 伐木场 / 铁匠铺，对中型护甲 +15%）。
  • 尖刺障碍升级从 3 级压缩为 2 级（改为 5 基础 + 攻击者伤害的 20% / 50%）。
  • 牛头人「粉碎」改为自带减伤版 + 升级版。
  • 科多兽「吞噬」可作用于无抗性皮肤的山岭巨人。
地图编辑器更新（面向重制版）
  • Lua 脚本支持（Beta）：地图可选 JASS 或 Lua（情节→地图选项→脚本语言）。
  • 对象修改系统 API：运行时修改物品 / 能力 / 单位等。
  • 地图以文件夹保存（以及 MPQ），结构可在编辑器外更新，利于多人协作开发。
  • 松散文件自动导入：地图以文件夹保存时，文件夹内资源自动识别导入，无需再经导入管理器登记。
  • 自定义界面函数：新增一批自定义界面原生函数，地图作者可增删、调整界面框架。
  • 官方战役地图可在编辑器打开。
  • 模型支持 256 骨骼。
BUG 修复
  • 修复触发器保存丢失、自定义电影播放、占有命令残留。
  • 修复多个地图反同步（DBZ / Builders and Fighters 等）、声音数据跨图传输。
  • 修复 OBS 切窗冻结、观察者全局战斗音效。
1.322020-01-28（含 1.32.1–1.32.10）重制版上线
里程碑：《魔兽争霸III：重制版》正式发布——重制版画面、战役部分重做、接入战网、收藏系统、MMR 匹配、中文配音、共享容器、修复叠字 BUG。
游戏功能性更新
  • 重制版画面：全部英雄 / 单位 / 建筑 / 环境高清重制；支持经典 / 重制双模式切换。
  • 战役部分重做：恢复 3 个原版试玩版序章任务（「风暴中的骑士们」等）；全部任务更新地形 / 难度并加入自动存档。
  • 战役美术重制：达拉然 / 银月城 / 斯坦索姆三城美术与布局重制；全部战役角色与视觉素材更新。
  • 收藏：英雄皮肤、头像、可解锁的战役与匹配奖励。
  • 多语言配音：在原有配音基础上，新增西班牙语（拉美）、葡萄牙语（巴西），并更新简体 / 繁体中文等 9 种语言。
  • 更多死亡音效：为大量单位补充 / 扩充死亡音效（1.32.2 修复了新的死亡音效在经典模式中被误播放的问题）。
  • 接入战网：从战网客户端安装 / 更新 / 启动，含群组与聊天；经典账号链接（保留历史战绩，90 天期限）。
  • 版本与定价：上架两档——标准版 $29.99（国服 ¥168）；战争嘉奖版 $39.99（国服 ¥258）。
  • 战争嘉奖版赠品：附赠 4 款英雄皮肤（阿尔萨斯 / 塞纳留斯 / 吉安娜 / 萨尔）。
  • MMR 匹配：1v1 / 2v2 / 3v3 / 4v4 / FFA 竞技匹配（隐藏 MMR，对局中用 !mmr 查看）。
  • MMR 匹配组队：可组队 2v2 / 3v3 / 4v4。
  • 共享容器（1.32.6）：安装目录拆分为 Data + _retail_（正式服）+ _ptr_（测试服）三类文件夹，正式服与测试服共用数据、可并存更新。
  • 热键与设置：新增 Grid / 传统热键布局；血条 / 队伍颜色 / 英雄状态条 / 冷却显示设置。
平衡性机制改动（主要在 1.32.10，2021-04-13）
  • 山岭巨人「第二次嘲讽」被移除（1.30 引入，1.32.10 回调）。
  • 人类伐木科技前置放宽：改良伐木移除前置、高级伐木由城堡改要塞；骑士默认自带「裂甲之刃」。
  • 亡灵：「埋骨地」不再需要牺牲深渊。
  • 物品与掉落池：各类光环类道具加成集体下调（如勇气勋章、战歌战鼓等）；所有物品回收价 50% → 60%。
地图编辑器更新
  • 1.32.x 修复期持续修复编辑器与自定义地图相关问题。
BUG 修复 / 已知问题
  • 1.32.1（发布首周）：修复了在高分辨率下中文字形叠加、对话乱码的叠字 BUG。
  • 1.32.1：修复加载任务误报失败、多面板导致自定义地图崩溃、经典模式渲染异常。
  • 上线初期已知问题：加载黑屏、古树根须放置图标缺失、非拉丁字符重叠、非美式键盘键位失效、跨平台无法邀请等，均在 1.32.x 逐步修复。
  • 编辑器相关：自定义地图 >256MB 破坏大厅、JassHelper 残留。
1.332022-08-17（原定 2022-08-10）排名系统
核心亮点：排名对战、玩家档案、排行榜三大系统，以及镜头缩放功能。
游戏功能性更新
  • 排名对战：排名 / 非排名可选；赛季结束后天梯重置。
  • MMR：每种族（含随机）独立 MMR；每种族 5 场定位赛；段位 8 级（从「未定级」到「冠军」）。
  • !Stats 命令查询对局内胜负与 MMR；排行榜可按种族 / 好友 / 模式筛选；玩家档案显示段位 / 生涯 / 历史。
  • 经典头像按总胜场解锁；自定义游戏全球化并可按时延筛选；新增芝加哥服务器；PopcornFX 升级 2.5.1。
  • 镜头缩放：滚轮缩放，PageUp/Down 调节，F5 复位，可设默认 / 最大缩放。
平衡性机制改动
  • 战役平衡重做：RoC 战役全量平衡重做 + TFT 轻度调整（含 AI 与脚本改动）。1.36.1 全部回滚。
编辑器更新
  • 世界编辑器启用 Windows 10 通用控件。
  • GPU 渲染器更新（字体渲染变化，-legacykerning 恢复旧字体）。
  • 旧版 Popcorn 特效错误提示。
BUG 修复
