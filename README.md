# worldeditor-zhcn
适用于《魔兽争霸 III：重制版》地图编辑器（World Editor）的纯净汉化补丁。
## 下载渠道
[直接下载](https://worldeditor.cn/wc3-editor-zhcn-0.6.0.zip)
[Github 下载](https://github.com/kobayashi1998/worldeditor-zhcn/releases)

## 使用说明
双击 AllowLocalFiles.reg，在弹出的提示窗口中点击确定。
将补丁中的 _retail_ 文件夹复制到游戏根目录即可。
*补丁使游戏优先调用本地文件，不涉及修改游戏本体；删除相关文件即可移除本补丁。*
